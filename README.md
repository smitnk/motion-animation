# Motion Animation

A native Android 2D drawing and animation studio.

## Current foundation

- Jetpack Compose Android application
- Drawing canvas and raster/vector drawing foundations
- Brush and eraser tools
- Layers
- Selection and transform foundations
- Animation frame/timeline foundations
- Onion skin, guides, snapping and ruler foundations
- PNG/GIF export paths
- Save/load project paths
- GitHub Actions Android debug-build verification
